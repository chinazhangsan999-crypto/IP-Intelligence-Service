# 运维后台

访问地址：

```text
https://<IP服务域名>/admin/
```

后台是带审计的运维与管理控制台，展示当前实例的：

- 服务就绪状态与运行时间；
- HTTP 请求量、查询 IP 数和慢请求；
- 进程与堆内存；
- PostgreSQL 连接池；
- 数据源版本、更新时间和可用状态；
- 自动更新器开关、运行状态和最近结果；
- 固定接口的请求数、平均耗时和 p95 上界；
- 当前页面打开后的请求/分钟与解析 IP/分钟趋势。

管理员还可以：

- 创建、暂停和重新启用导航站 API 接入方；
- 轮换接入密钥，密钥仅在生成时展示一次；
- 查看各接入方最近 24 小时请求、IP 和错误量；
- 新增或启停 ASN、ASN 组织名称和 CIDR 判断规则；
- 手动启动一次数据源更新；
- 查看最近更新任务与审计记录。

## 登录方式

后台不再使用监控令牌登录。首次部署后运行 `npm run admin:account -- admin` 创建管理员，命令会生成一次性初始密码。登录后可在“账户安全”中修改账号或密码。

`METRICS_TOKEN` 仅供 Prometheus 抓取 `/metrics` 使用，与后台账户相互独立。

页面外壳可以直接加载，但没有有效管理员会话无法读取任何运行或管理数据。生产环境必须使用 HTTPS，并建议由 Cloudflare Access 或反向代理再加一层管理员准入。

## 数据边界

后台不展示或保存：

- 被查询的原始 IP；
- 导航站 HMAC 密钥；
- 签名和 Nonce；
- 逐请求客户端身份；
- API 请求体。

后台不会展示已保存的密钥密文、主密钥、原始查询 IP、签名或 Nonce。所有写操作均要求独立管理员会话、同源请求和 CSRF 令牌，并写入审计日志。

## 刷新策略

- 登录后立即加载；
- 每15秒刷新；
- 浏览器标签页不可见时暂停；
- 返回标签页后立即刷新；
- 单次请求8秒超时；
- 临时失败保留当前页面并提供重试，不会自动退出；
- 令牌失效时返回登录页。

趋势图仅保存当前浏览器页面会话的最近60个采样点，最多约15分钟。跨重启和长期趋势由 Prometheus 保存。

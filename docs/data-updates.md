# 数据自动更新

第 8 步提供定时检查、下载验证、备份替换、失败回滚、整套热重载和 PostgreSQL 更新记录。更新任务只改变 IP 数据版本，不改变 API 字段含义或判断优先级。

## 默认计划

生产环境示例配置：

```env
IP_DATA_AUTO_UPDATE_ENABLED=1
IP_DATA_UPDATE_INTERVAL_HOURS=6
IP_DATA_UPDATE_STARTUP_DELAY_SECONDS=60
```

服务启动 60 秒后执行第一次检查，之后每 6 小时执行一次。同一进程不会重叠运行；多实例部署时使用 PostgreSQL advisory lock，只有取得锁的实例执行更新。

自动更新默认关闭，必须显式设置 `IP_DATA_AUTO_UPDATE_ENABLED=1`。这样开发机和测试进程不会自行访问外部网络。

## 更新频率

| 数据 | 检查频率 | 实际下载规则 |
|---|---:|---|
| DB-IP City Lite | 每轮检查 | 本地版本不是当前 UTC 月份时，City 与 ASN 成对下载 |
| DB-IP ASN Lite | 每轮检查 | 与 City 保持同月，不能只替换其中一个 |
| AWS/GCP/Cloudflare 网段 | 每轮检查 | 下载官方当前列表并重新生成统一文件 |
| Tor 出口节点 | 每轮检查 | 主列表失败后尝试 Onionoo；两者都失败时保留旧文件 |
| IP2Proxy Lite | 每轮调度时判断是否到期 | 启用后每 7 天使用服务器下载令牌检查并替换 LITE BIN；下载令牌永不写入数据库、日志或 Git |
| 自定义分类规则 | 不覆盖 | 本地和 PostgreSQL 管理规则属于人工配置 |

## 安全替换流程

```text
检查目标版本
  → 下载到随机临时文件
  → 限制压缩与解压后大小
  → 解析格式并校验最小记录数
  → MMDB 实际打开并查询样本 IP
  → 计算 SHA-256
  → 旧文件改名为临时备份
  → 新文件切换到正式路径
  → 全部成功后删除备份
```

City 与 ASN 作为一个版本对替换；中途失败会恢复旧文件。开放网段和 Tor 是独立可选来源，一个来源不可达不会删除另一个来源或现有文件。

## 热重载

文件更新后，服务先重新打开全部必需数据库。只有 City 和 ASN 都能成功加载，才构建新的完整查询服务并一次性切换：

- 正在执行的请求继续使用旧查询快照；
- 切换后的新请求统一使用新快照；
- 不存在 City 新版配 ASN 旧版的混用窗口；
- 可选来源加载失败时继续使用其旧内存版本；
- 不需要重启 Node.js 服务。

## 状态与可观测性

每轮任务写入 PostgreSQL `update_jobs`：

- 开始和完成时间；
- 成功、失败状态；
- DB-IP 与开放网段的分项结果；
- 新版本、SHA-256、文件大小和记录数量；
- 热重载后的数据源版本；
- 失败原因与总耗时。

`data_source_versions` 同步保存当前活动版本、更新时间、过期时间和最近校验状态。City/ASN 超过 45 天、云网段超过 48 小时、Tor 超过 24 小时会显示 `stale`，但已有数据仍可查询；文件缺失或无法解析才显示 `unavailable`。

## 手动运维命令

```powershell
npm run data:update-dbip
npm run data:update-open
npm run data:update-ip2proxy
npm run data:update-all
```

`data:update-dbip` 在本月版本已经存在时只返回 `current`，不会重复下载百兆数据库。手动运行脚本只替换文件；已经运行的服务要立即使用新文件，应等待下一次自动热重载，或重启服务。

IP2Proxy 自动下载默认关闭。启用时需要在服务器私有 `.env` 设置 `IP2PROXY_AUTO_UPDATE_ENABLED=1`、下载令牌、数据库代码 `PX12LITEBIN` 和更新间隔；当前调度会调用更新器，但更新器会根据本地成功检查时间确保每 7 天最多下载一次。下载文件需通过 ZIP 条目、大小、BIN 打开、版本与 SHA-256 校验，失败时保留当前版本。

## 故障边界

- 下载、解压、校验或替换失败：旧文件和旧内存快照继续服务；
- 一个可选来源失败：其他成功来源仍然重载；
- 更新过程中收到停机信号：终止子进程，不启动下一轮；
- 多实例竞争：未取得数据库锁的实例直接跳过；
- PostgreSQL 更新记录失败：本轮标记失败，不影响旧查询快照；
- 不把下载错误转换成空数据库，也不把 `null` 转成 `false`。
